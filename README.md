**Your personal corner of the entertainment world.**

Dowatch is an Android watchlist application designed to help you organize the movies and TV shows you want to watch, are currently watching, or have already completed, all in one place.

Discover titles, manage your watchlist, track your progress, and keep your personal ratings and reviews together in an interface designed to make browsing feel cinematic.

## ✨ Features

- 🔎 **Search & Discover:** Search for movies and TV shows using TMDb.
- 🎬 **Personal Watchlist:** Keep your entertainment list organized in one place.
- 📌 **Status Management:** Categorize titles by their watching status.
- ⭐ **Personal Ratings & Reviews:** Rate titles and record your own thoughts.
- 📝 **Personal Notes:** Keep notes about the titles you add.
- 📅 **Upcoming Titles:** Keep track of planned releases and dates.
- 🎨 **Cinematic Interface:** Artwork, fading backdrops, custom colours, and carefully designed detail screens.
- 💾 **Local Storage:** Save your watchlist locally using Room.
- 🐥 **DoChick:** Meet the little mascot that gives Dowatch its identity.

## 🚀 Getting Started

### Requirements

- Android device compatible with the app's configured minimum SDK
- Android Studio, if building from source
- A TMDb API key for API-powered features

### Installation

1. Download the APK from the project's GitHub Releases.
2. Open the downloaded APK on your Android device.
3. Allow installation from that source if Android asks for permission.
4. Install and launch Dowatch.

### Building From Source

1. Clone the repository:

   ```bash
   git clone https://github.com/Nivedhniv/fantasico-watchlist.git
   ```

2. Open the project in Android Studio.
3. Configure your TMDb API credentials using the project's expected configuration.
4. Sync Gradle and build the application.

**Important:** Never commit API keys, passwords, or other secrets to the repository. Follow TMDb's current API attribution and usage requirements.

## 🎞️ What Dowatch Is (and Isn't)

Dowatch helps you organize and track your entertainment watchlist. It does **not** stream, host, or provide access to movies or TV episodes.

Movie and TV show information is provided through TMDb. Dowatch is an independent project and is not endorsed by or affiliated with TMDb.
